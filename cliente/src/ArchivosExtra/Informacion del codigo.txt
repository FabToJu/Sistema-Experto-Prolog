
FLUJO DE INFORMACION

Main
  │
  ├── 1. Modelo()
  │         Inicializa listas de datos
  │
  ├── 2. Vista(modelo)
  │         Recibe el modelo
  │         Llena los JComboBox con los getters del modelo
  │         Construye todos los componentes gráficos
  │
  └── 3. Controlador(modelo, vista)
            Recibe modelo y vista
            Llama a vista.setControlador(this)
            Registra todos los listeners
            │
            │  El usuario selecciona preferencias y presiona Generar
            │
            ▼
         Controlador.generarPlaylist()
            │
            ├── Lee vista.getEstado()
            ├── Lee vista.getActividad()
            ├── Lee vista.getEnergia()
            │
            ├── Llama modelo.obtenerGenero(estado, actividad, energia)
            │         │
            │         ├── retractall limpia hechos dinámicos anteriores
            │         ├── assertz inyecta nuevos hechos
            │         ├── consulta recomienda(Genero)
            │         └── retorna género como String
            │
            ├── Llama modelo.obtenerPlaylist(estado, actividad, energia)
            │         │
            │         ├── consulta obtener_playlist(Genero, Titulo, Artista)
            │         └── retorna List<String[]>{genero, titulo, artista}
            │
            └── Llama vista.mostrarResultados(genero, playlist)
                      │
                      ├── Actualiza generoLabel
                      ├── Llena la tabla con las canciones
                      └── Muestra el panel de resultados


Flujo del menú Base de Conocimiento

Usuario hace clic en un item del menú
            │
            ▼
      Controlador recibe el evento
            │
            ├── Ver Hechos
            │     └── vista.mostrarDialogoHechos()
            │               └── Lee sección HECHOS del .pl
            │                   Muestra en JTextArea
            │
            ├── Ver Reglas
            │     └── vista.mostrarDialogoReglas()
            │               └── Lee sección REGLAS del .pl
            │                   Muestra en JTextArea
            │
            ├── Agregar Hecho
            │     └── vista.mostrarDialogoAgregarHecho()
            │               │
            │               │  Usuario llena el formulario
            │               │  y presiona Agregar
            │               │
            │               └── Controlador.confirmarAgregar()
            │                     ├── Lee tipo, valor, título, artista
            │                     ├── Construye hecho en formato Prolog
            │                     ├── vista.agregarHechoAlArchivo(hecho)
            │                     └── vista.limpiarCamposAgregar()
            │
            ├── Eliminar Hecho
            │     └── vista.mostrarDialogoEliminarHecho()
            │               │
            │               │  Usuario selecciona un hecho
            │               │  y presiona Eliminar
            │               │
            │               └── Controlador.confirmarEliminar()
            │                     ├── Lee vista.getHechoSeleccionado()
            │                     ├── vista.eliminarHechoDelArchivo(hecho)
            │                     └── vista.eliminarHechoDeLista(hecho)
            │
            └── Consulta Simple
                  └── vista.mostrarDialogoConsulta()
                            │
                            │  Usuario selecciona tipo,
                            │  ingresa valor y presiona Consultar
                            │
                            └── Controlador.ejecutarConsulta()
                                  ├── Lee tipo y valor
                                  ├── modelo.consultarHecho(tipo, valor)
                                  └── vista.mostrarResultadoConsulta(resultado)
